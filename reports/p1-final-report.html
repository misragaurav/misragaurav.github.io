Final Report Project 1

Does a language model notice a thought you put into it?

Gaurav Misra, November 2026. Models studied: Qwen2.5-1.5B-Instruct and Gemma 3 4B (instruction-tuned). 487,968 trials with an injection and 551 readings with nothing injected (488,519 forward passes) over eight runs, all on one laptop, with no training.

Short version. When a concept vector is added to a language model's activations and the model is asked "Do you detect an injected thought?", it sometimes says yes. I asked whether that yes reflects sensitivity to the injection or a response bias towards "Yes", using the tools of signal detection theory.

  • Qwen2.5-1.5B: response bias. Injection raises "Yes" as much on unrelated questions as on the detection question, and the model also agrees that no thought was injected.
  • Gemma 3 4B: a convincing pattern that did not replicate. At one layer, a detection-like pattern survived matched controls, random vectors and lexical controls, then failed a replication whose tests I had fixed in advance.
  • Why it failed: how the vectors were built. About half of the original pattern came from my choice of baseline words, the list subtracted to make each concept vector. A model that really detected injected thoughts would not care how the vector was built, so this counts against detection.

1. The question

Two recent studies (Lindsey, 2025; Macar et al., 2026) add a concept vector, for example one for bread, to a language model's internal activations and then ask it whether it notices an injected thought. Sometimes it says yes, and sometimes it even names the concept.

A yes can mean two very different things:

  1. The model has some access to its own internal state and notices the intrusion. That would be a form of introspection.
  2. The injected pattern simply makes the word "Yes" more likely, whatever the question.

I spent four years measuring pain in people with EEG, fMRI and EMG. A participant who presses "I feel it" on every trial, including catch trials where nothing was delivered, does not have a low pain threshold; they have a liberal criterion. Signal detection theory separates the two: sensitivity (d′), how well an observer tells signal from noise, and bias, how ready the observer is to say "yes" at all. The proportion of "yes, I detect it" answers, which is the headline number in the published experiments, mixes the two.

The injected-thought experiment (Lindsey, 2025) measures false alarms and tests whether concept injection makes a model generally more likely to say "yes". Those controls give evidence that the models can sometimes discriminate injection from no injection. The paper stops short of estimating sensitivity (d′) and response criterion (c) separately, so its model rankings leave open how much of the difference comes from each. It makes a stronger case that an injected concept can influence what a model accurately reports than it makes for the claim that Opus has greater introspective sensitivity than other models. For that comparison, I would score the initial yes/no decision identically on injection and control trials, estimate d′ and c with uncertainty for each model, and report concept-identification accuracy separately.

The first test any psychophysicist would run is to ask control questions that have nothing to do with injection, and see whether injection pushes those towards "Yes" too. This project does that, and then adds one control at a time, as each result demanded.

2. How a thought is put into the model

The residual stream. A transformer language model processes text as a sequence of tokens. At every layer, each token position carries a long vector (1,536 dimensions in Qwen2.5-1.5B, 2,560 in Gemma 3 4B), called the residual stream. Each block of the model reads it and adds its own update. "Layer L" below means the residual stream just after block L has added its update.

Building a concept vector (a difference-of-means vector):

  1. Wrap "Tell me about bread." in the model's chat format, ending where the assistant's reply would begin, and run the model once with nothing injected.
  2. Record the residual stream at the last token position, at every layer, in that one forward pass. The last position is used because, by the middle layers, attention has gathered the whole request there: the model predicts its next word from that position alone, so it holds something like "about to talk about bread".
  3. Do the same for a list of plain baseline words and average them.
  4. Concept vector = activation for "bread" − mean activation for the baseline words.

The subtraction removes what is common to "being asked to tell about a noun" and leaves what is particular to bread. It is the same logic as a contrast map in imaging (task minus control), and, as section 8 shows, it has the same weakness: the result is only as clean as the control condition.

Why subtract a baseline at all? A simpler experiment would inject the raw activation vector of a word, the residual stream recorded at the last token position for "Tell me about bread.", on test trials and nothing on control trials. That experiment is enough to answer one question: does adding the raw activation make the model more likely to say "yes" than on control trials? The subtraction (word vector minus baseline vector) does two more things. It makes the result easier to attribute specifically to the concept, because what every request shares (the chat format, being asked to talk about something) has been removed. And it allows a second experiment: checking whether the model knows which concept was inserted, since each concept vector now carries mainly what is particular to its own word.

The sham. For every concept vector there is a random vector of the same norm (length): it disturbs the model by the same amount but carries no meaning. It plays the role of sham stimulation.

Injecting it. During a trial, a forward hook (a small function PyTorch runs as the model computes) adds strength × vector to the output of block L, at every token of the final question. The model's weights never change, and the hook is removed after each trial. Because the vector is added to block L's output, blocks L+1 onwards process it: in Gemma 3 4B (34 blocks), an injection at layer 15 passes through 18 more blocks, and one at layer 26 through only 7.

The response. The model is asked to answer with one word. Instead of sampling an answer, I read the probabilities it assigns to "Yes" and to "No" at the last position, and use the log-odds between them, log(P(Yes) / P(No)), as a continuous decision variable. The model's output is deterministic for a given input, so there is no measurement noise in a single trial: the uncertainty comes from which concepts and questions were sampled, and intervals are bootstrapped over concepts. Each forward pass tests all 50 concepts at once, one per row of the batch.

Trials, questions and conditions. Four terms are used throughout.

  • Injection trial and no-injection trial. On an injection trial a vector is added; on a no-injection trial nothing is. Every question is asked in exactly the same words on both. (The experiment's instructions to the model call no-injection trials "control trials", which is why the reversed question below uses that phrase.)
  • Shift. For one question, the log-odds of "Yes" on an injection trial minus the log-odds of "Yes" for the same question on a no-injection trial. It is how far injection moved the answer.
  • Detection questions and control questions. Detection questions ask about injection ("Do you detect an injected thought?"). Control questions ask about something else whose answer is fixed ("Is Brazil in Africa?"). Both kinds are asked on the same injection trials, so "control question" (a different question on the same trial) is not the same thing as "no-injection trial" (the same question with nothing injected).
  • Condition. One combination of injection layer and injection strength, for example layer 15 at strength 3. Each condition's numbers are averages over all 50 concepts and all prompts. When a result is reported "in 5 of 6 conditions", it means 5 of the 6 layer-and-strength combinations tested.

Strength units. Strength is a multiple of the concept vector itself. In the units used in my emotion project, Do emotion readouts in a language model agree, and are they specific? (a fraction of the typical activation length at that layer), one unit of strength is about 0.019 at Gemma's layer 15 and 0.048 at layer 20, and between 0.06 (layer 8) and 0.36 (layer 22) in Qwen. So Gemma's strengths of 2 to 4 at layer 15 are gentle pushes of 4% to 8% of the typical activation, while Qwen's late layers received much larger ones. A fixed fraction-of-norm scale was tried and dropped, because Gemma's answers broke down at 7% of the norm in one layer and 23% in another.

The two halves of the detection pattern. There are two kinds of detection question, and the reversed one is the decisive control.

  • The standard question ("Do you detect an injected thought?" and 7 other wordings). Its correct answer on a no-injection trial is "No".
  • The reversed question ("Is this a control trial with no injected thought?" and 3 other wordings). Its correct answer on a no-injection trial is "Yes".

A model that detects the injection should answer "Yes" more often to the standard question and "Yes" less often to the reversed question: more "Yes" to "Was a thought injected?" and less "Yes" to "Was no thought injected?". I call these the two halves of the detection pattern, and detection needs both, each beyond matched control questions. A model that simply leans towards "Yes" produces the first half and the opposite of the second.

The control question families. Every detection question is compared with control questions that have the same correct answer, and so start from a similar point: a question the model confidently answers "No" can only move towards "Yes", and one it confidently answers "Yes" only towards "No". The control questions come in six families of six questions each, all asked on the same injection trials as the detection questions.

Conversation questions, answer No "Is there an image attached to this message?", "Is this conversation taking place in French?" No Standard question

The fact and conversation families are the main yardstick. The lexical families are a separate check, explained in section 6. A detection question's movement beyond matched controls is its shift minus the shift of its control questions: how much further it moved than questions with the same correct answer.

The closest control family. Movement beyond controls can be computed against the fact family or against the conversation family, and the two can disagree. The strictest version uses, for each detection question, the family that leaves the smaller detection effect. In symbols:

  • Shift of a question q: Δq = log-odds of "Yes" to q on an injection trial − log-odds of "Yes" to q on a no-injection trial, averaged over concepts, prompts and the valid strengths. Δq > 0 means injection moved the answer towards "Yes".
  • Standard question (S), compared with the two answer-No families, fact (FNo) and conversation (CNo):
    S = min( ΔStandard − ΔFNo, ΔStandard − ΔCNo ).
    Taking the minimum is the same as subtracting the larger of ΔFNo and ΔCNo, the family that moved further towards "Yes". Detection predicts S > 0.
  • Reversed question (R), compared with the two answer-Yes families, FYes and CYes:
    R = max( ΔReversed − ΔFYes, ΔReversed − ΔCYes ).
    Taking the maximum is the same as subtracting the smaller (more negative) of ΔFYes and ΔCYes, the family that moved further towards "No". Detection predicts R < 0.

The minimum and maximum each pick whichever family is less favourable to detection, so a pattern that survives this comparison does not depend on choosing a convenient family. From section 6 on, every number for the standard question "beyond the closest control family" is S, and every such number for the reversed question is R.

4. Result 1. Qwen2.5-1.5B: response bias

In the first full run, injection raised the log-odds of "Yes" on the detection question by +3.47 at layer 22, strength 2 (ROC area 0.96, d′ 2.5). Taken alone, that looks like excellent detection. It is not:

Figure 1. Qwen2.5-1.5B, experiment A2, concept vectors at strength 2. Each bar is the change in the log-odds of "Yes" caused by injection. The detection question (green) moves no more than questions about geography or the conversation (grey), and the reversed question (rust), which a detecting model should answer "No", moves just as far towards "Yes".

  • The reversed question rose with the standard one. Over the conditions where injection clearly works, the standard question moved +3.17 and "Is this a control trial with no injected thought?" moved +2.90. The model agrees that a thought is present and that none is present, on the same trials. Only response bias predicts that.
  • Concept and random vectors do the same. In layers 17, 20 and 22 the concept-versus-sham gap averages −0.004.
  • A methods lesson from the first run. The naive contrast, detection shift minus control shift, came out positive in places (up to +0.70). That was an artefact: questions a model is unsure about move further than questions it is sure about, and the detection question happened to be one it was unsure about. This is why every later comparison uses controls matched on starting point.

Across 265,373 trials in two experiments, the "Yes" that follows injection in Qwen2.5-1.5B is response bias.

5. Result 2. Gemma 3 4B: a pattern that survived the controls

Gemma behaves differently from the start. Before anything is injected it is confident and consistent: about −10 log-odds on "Do you detect an injected thought?" (odds of roughly 20,000 to 1 for "No") and about +13 on the reversed question. It also follows the stated base rate (slope 1.04, close to the ideal 1).

A random vector is not inert in Gemma: it makes the model less sure of everything, so confident "No" answers drift up and confident "Yes" answers drift down. That alone makes the standard question rise and the reversed question fall, which looks like detection. So the test becomes the matched-control test: did each detection question move further than control questions that started from the same point?

Each marker is one layer and strength: how far the standard question (horizontal) and the reversed question (vertical) moved beyond control questions with the same starting point. Detection predicts the shaded lower-right quadrant. Open markers are conditions excluded from the tests because the injection broke the answer format: under the concept vector or the random vector at that layer and strength, the model put less than half of its probability on the words "Yes" and "No" combined, so its next word would most likely have been something else, and a Yes-versus-No comparison means little there. At layers 20 and 26 any disturbance produces the pattern, so it is not about the concept there. At layer 15 it took a concept vector: at strength 4 the model answered "Yes" outright to the standard question on 56% of trials, from essentially 0% without injection.

6. Result 3. The Gemma pattern is not caused by the question's words or by one shared direction, and naming the concept is mostly priming (experiment A3)

A2 left simpler explanations standing. The detection questions might respond to injection because of the words they contain ("thought", "injected"), not because they ask about the model's state. Or all concept vectors might share a common direction, meaning something like "a concept is in mind", that tilts any question about thoughts with no self-monitoring involved. And the published finding that a model can name the injected concept needs its own control. A3 (60,904 trials, layers 15 and 20) tested all three.

  1. The pattern appeared again. A3 injected at two layers (15 and 20) at three strengths each (2, 3 and 4), which makes six conditions. With whole concept vectors, both halves of the detection pattern appeared, with 95% intervals excluding zero, in 5 of the 6: all three strengths at layer 15 and two of the three at layer 20.

  2. It is not the words of the question. The detection questions are full of particular words: inject, thought, mind, detect. A concept vector might change how the model handles those words, for example by making anything about thoughts and minds read differently, without the model checking anything about its own state. The detection questions would then move simply because of their vocabulary. The lexical questions (the last two families in the table in section 3) test this. They reuse the same words, but their answers are fixed facts about the words themselves or about the instructions, so they do not depend on whether anything was injected: "Does the word thought begin with the letter t?" (Yes), "Is the word mind the name of a planet?" (No). They are asked on the same injection trials as the detection questions and measured the same way, as movement beyond the fact and conversation questions with the same answer. If the vocabulary were driving the effect, lexical No questions would rise like the standard question and lexical Yes questions would fall like the reversed one. They did not: beyond the fact and conversation questions, they moved −0.26 (answer No) and +0.10 (answer Yes), close to zero, against +3.24 for the standard question and −2.39 for the reversed question.

  3. Neither part of the vector produced the pattern alone. Every concept vector was split into two parts that add up to it exactly. There is no dot product or projection here, only averaging and subtraction. Write v₁ … v₅₀ for the 50 concept vectors at one layer, each with 2,560 dimensions.

    • Shared part: m = (v₁ + v₂ + … + v₅₀) / 50, the element-by-element average. It is the same for every concept.
    • Specific part of concept i: rᵢ = vᵢ − m, what is left of that concept once the average is removed. So vᵢ = m + rᵢ.

    For injection, each part was rescaled to the length of the whole concept vector it came from (m divided by its own length, times the length of vᵢ; the same for rᵢ). Each part injected alone therefore disturbed the model exactly as much as the whole vector and its random vector did, and any difference comes from direction, not size. (The replication in section 7 also injected the parts at their natural size.) If the shared direction explained the pattern, the shared part alone should reproduce it; if the concept's own content did, the specific part should. The table gives how far each detection question moved beyond its closest control family (section 3), at layer 15:

Injected Standard question beyond controls Reversed question beyond controls
Whole concept vector +3.17 −2.35
Specific part alone +0.98 +0.03
Shared part alone −0.41 −0.59
Random vector +0.58 +0.61

  1. Naming the injected concept was almost all priming. The published experiments report that a model can sometimes say which concept was injected, not only that something was. That could be introspection, or it could be priming. In psychology, priming means that exposure to a stimulus makes related words come to mind more easily, without any awareness of the stimulus: after seeing "bread", people recognise "butter" faster. Adding the bread vector to the model's activations is a very direct kind of priming. It pushes the model towards talking about bread, so the word "bread" becomes more likely in whatever it says next, whether or not anything in the model registers that an injection happened.

    To separate the two, each trial offered two words, the injected concept and another one, in two questions:

    • Identification question: "If a thought is being injected on this trial, it is about one of these two words: bread or silver. Which word is it about?"
    • Neutral question: "Here are two words: bread or silver. Choose either one of them; it does not matter which." It never mentions injection.

    Priming alone predicts the same pull towards the injected word on both questions. Identification beyond priming predicts a larger pull on the identification question. The result: on the neutral question, injection pulled the answer +11.4 log-odds towards the injected word, odds of roughly 90,000 to 1. Asking about "the injected thought" added only +1.2 on top (about 11% more), with its 95% interval above zero in 2 of 3 valid conditions. So the model's ability to "name the thought" is almost entirely the injected word being primed. At most a small part could reflect the question about injection.

At that point the result looked positive but narrow: the pattern needed an intact concept vector, at one layer, in one model. I wrote at the time that it rested on "one model, one layer, my approximate word list". The last of those turned out to matter most. (The closest-family comparison in point 3 was chosen after seeing the data, which is one reason the next step was a replication with its tests written down first.)

7. Result 4. Repeating the Gemma experiment with the published word lists and tests written down in advance: the pattern did not hold

Why repeat it. By the end of A3 the Gemma pattern had survived every control I had designed. But several of those comparisons, including the closest-family comparison above, were chosen after I had seen the data, and a comparison chosen that way can end up fitting noise. Two other weaknesses remained. My concept and baseline words were my own approximation of the lists used in the published work, not the lists themselves. And the pattern had been seen in one model at one layer. A result that rests on a test chosen afterwards and on one stimulus set is exactly the kind that fails to replicate.

How. I did what a clinical trial does with a pre-registered analysis. I wrote down three tests and the thresholds each had to meet, committed them to version control, and only then ran the experiment again (43,248 trials, layer 15, strengths 2, 3 and 4).

  • What changed, on purpose: I switched to the concept and baseline words used by Macar et al. (2026): 50 concept words and 100 baseline words, copied from the public code released with that study. The shared and specific parts of each vector were also injected at their natural size, not only rescaled to a whole vector's length.
  • What stayed the same: the model, the layer, the strengths, every question, the random vectors and the analysis code. The norming step, which picks control questions with the same starting point as each detection question, picked exactly the same control questions as before. It should: starting points are measured with nothing injected, so they cannot depend on the word lists.

The three tests, in plain words.

  1. Do both halves of the detection pattern (section 3) appear, by the strictest comparison? Averaged over the valid strengths, the standard question must rise at least 1 log-odds more than its closest control family, and the reversed question must fall at least 1 log-odds more than its own. The whole concept vector must meet both, and no other stimulus may.
  2. Is the pattern reliable at individual strengths? At 2 or more of the 3 strength levels chosen (2, 3 and 4), the whole concept vector must show both halves with 95% intervals that exclude zero, and the random vector must show this at none.
  3. Are the question's words ruled out again? At the strengths that show the pattern, the lexical controls must move at most a quarter as far as the detection questions.

What happened.

2. Both halves at individual strengths concept vector at 2 or more of the 3 strength levels chosen, random vector at none 3 of 3 0 of 3 (random vector: 0 of 3) Failed

What it means. One half survived and one did not. The standard question ("Do you detect an injected thought?") still rose more than its matched controls, at all three strengths with concept vectors and at none with random vectors, though by about half as much as before. The reversed question ("Is this a control trial with no injected thought?") no longer fell; it rose slightly. A model that noticed the injection should answer that question "No" more often, and this one did not. Detection needs both halves, so what is left in Gemma is a concept-specific push towards "Yes" on the standard question: a bias of some kind, not detection.

By the rules fixed in advance, the Gemma detection pattern did not replicate. Since only the word lists had changed, the next question was what in the word lists had produced the original pattern.

8. Result 5. Why it failed: my baseline words put the same extra direction into every concept vector

What the baseline does to every vector. Each concept vector is the concept word's activation minus the average activation of the baseline words. The same baseline average is subtracted from all 50 concept vectors. If the concept words and the baseline words are the same kind of words on average, the two averages nearly cancel, and each vector keeps mostly what is particular to its own concept. If the two lists differ systematically, every vector also carries one extra direction: the average concept word minus the average baseline word. I call this the shared part. It is simply the average of the 50 concept vectors.

How the two pairs of lists differ. My baseline was 50 words chosen to be plain: short, singular, lowercase names of concrete everyday objects (table, chair, cup, ladder, spoon). My concept list was mixed on purpose. It also contained everyday things (bread, mirror, clock, phones, bags), but alongside abstract words (justice, betrayal, happiness), natural phenomena (volcano, thunder, avalanches) and many plurals. The published lists are mixed in the same way on both sides: 50 concept words (Dust, Satellites, Sadness, Bread) and 100 baseline words (Desks, Laughter, Galaxies, Honey, Justice), mostly plural and capitalized. So their two averages nearly coincide.

Figure 3. The shared part of the concept vectors in three runs on Gemma 3 4B, at layer 15. Each bar is the length of the average of the 50 concept vectors (the one direction they all have in common), divided by the typical length of a single concept vector. A value of 0 would mean the vectors share nothing; 1 would mean they are all the same vector. With my word lists (A3, green) the shared part is about two-thirds of a typical vector's length, so a large part of every injection was the same direction, whichever concept it was meant to be. With the published concept and baseline words (replication, rust) it nearly vanishes. Keeping the published concept words but subtracting my baseline instead (add-back test, blue) brings it back, which shows that the shared part comes from the baseline.

What the shared direction is not. In my earlier notes I described it as roughly "not a household object", on the reasoning that my baseline was all household objects and my concepts were not. That was wrong. My concept list contains household items too, and they do not carry less of the shared direction: "bread" is among the concepts that carry the most of it (0.84 of the vector's length lies along it) and "clock" among those that carry the least (-0.23). Here, and only here, a dot product is used: how much of a concept vector lies along the shared direction is the dot product of the two divided by both lengths, which is their cosine similarity. What the shared direction means is not known.

Where it comes from is known: the baseline. The two runs that subtracted my baseline used different concept words, yet their shared directions point almost the same way (cosine similarity 0.87). The run that used the published baseline points elsewhere (0.50). The lists also differ in form: my baseline is singular and lowercase, while most of the published concept words are plural and capitalized. Within my own concept list, plural words carry more of the shared direction than singular ones (0.72 against 0.55 on average). Grammatical form is therefore one candidate ingredient, not a demonstrated one.

The add-back test. To test directly whether the baseline caused the failure, I ran an add-back experiment, the same logic as knocking a gene out and restoring it. The replication had removed the shared part by switching to the published lists, and the pattern went away. This run put it back: the published concept words, minus my baseline, with nothing else changed (43,248 trials, layer 15, prediction written down before the run). Because only the baseline changed, every concept vector here is the replication's vector plus one fixed vector. Because the concept words were the same as in the replication, the two runs can be compared concept by concept.

  • The manipulation check passed: the shared part came back (0.75 of a typical vector's length).
  • The standard question came all the way back (+3.62).
  • The reversed question moved the predicted way, from +0.70 to −0.75. Concept by concept, the change was −1.45 (95% interval −2.78 to −0.18), and the standard question changed by +2.11 (+1.44 to +2.88). Both intervals exclude zero.

An honest note on that last test. The plan I committed set a threshold of −1 on the level the reversed question reached. It reached −0.75, so by the rule fixed in advance the explanation is not confirmed. I judged that threshold arbitrary, because an add-back experiment asks about the change, and adopted the paired test of the change after seeing the data; by that test it is supported. Both labels are always reported together, and the deviation is logged in the plan. A test chosen afterwards is weaker evidence than one fixed in advance.

On the reversed question the first two runs differed by 3.05 log-odds, and the baseline words account for 1.45 of that, about half. The rest is not yet explained. My concept words are the obvious suspect, and run-to-run variation is possible.

9. Why it matters how the vector was built

The question is about the model's internal state, so it is fair to ask why the recipe for the injected signal should matter at all.

If the model really detected injected thoughts, it wouldn't. Detection is a claim about the fact of an injection, so it should hold whichever reasonable baseline the vectors are built against. In Gemma it did not: changing only the baseline words changed the result, and restoring them brought back about half of it. So the pattern was tracking something the vectors themselves carried, not the fact that something had been injected.

Four points make this concrete.

  1. Detection is never observed directly. It is inferred from a behavioural pattern, and the question is always what else could produce that pattern. The injected vector is not a neutral marker that says "something was added". It is a direction in activation space with a meaning of its own, and that meaning can change how the model reads the question, without any self-monitoring.
  2. My baseline made a large part of every vector the same direction. I thought I was injecting 50 different thoughts. I was injecting one direction 50 times, about two-thirds of a typical vector's length, plus a concept-specific part. A pattern that seemed to generalise across 50 concepts was mostly one direction's effect, counted 50 times.
  3. That shared direction plausibly interacts with the reversed question's wording. Whatever it means, a direction added to every injection could lower "Yes" to "Is this a control trial with no injected thought?" through the meaning of the words alone.
  4. Random vectors already showed that the model is not detecting injection as such. A random vector is also an injection, and at layer 15 the model did not respond to it this way. The response was always to this particular content, and once an effect depends on content, how the content was made becomes the central question.

The neuroscience version. Suppose you test whether people can detect a TMS (transcranial magnetic stimulation) pulse to a body-sensing region, and they say "yes, I felt it". But the coil also clicks, and it sits where it twitches a scalp muscle. People are reporting the click and the twitch, not the cortical stimulation. The check is to change how the pulse is delivered while keeping its cortical effect, and see whether the reports change. My baseline words were the click.

10. Takeaways

  1. In neither model does anything that looks like detection survive matched controls and a pre-specified replication, with a forced one-word answer.
  2. If a model really detected injected thoughts, how the vector was built would not matter. In Gemma it did. The practical rule: vary the baseline on purpose, and treat a result that holds for only one baseline as a property of the stimulus, not of the model.
  3. An apparent introspection signal can come from at least three places, and each needs its own control: response bias (Qwen), general disturbance (random vectors in Gemma's deeper layers), and the construction of the stimulus itself (Gemma at layer 15). The third is the least obvious and the most transferable: anyone building concept vectors by subtracting a baseline is choosing a contrast, and the contrast is part of the stimulus.
  4. It is the same lesson as in imaging. A contrast map is only as clean as its control condition, and "pain minus rest" is not "pain minus touch". I knew this about fMRI and had to learn it again about language models.
  5. Pre-specification earned its keep. The Gemma pattern survived every control I designed after seeing the data. It took a replication with its tests written down first to show it did not hold.

11. Limits

  • Two small models (1.5 and 4 billion parameters). The published work concerns much larger ones, and introspective abilities, if they exist, may appear only at scale.
  • A forced Yes or No. The published experiments let the model answer freely, and sometimes it names the injected concept. This design cannot see that.
  • No positive control. There is no case in which this method is known to find real sensitivity, so a null result in these models cannot rule it out in others.
  • One way of injecting. The vector was added at every token of the question. Injecting at the last position only, which the code supports, was never run.
  • Half of the Gemma pattern is still unexplained after the add-back test.

12. What I would do next

  • Vary the baseline deliberately, as a control condition in its own right, and report results across baselines.
  • Inject at the last token only, so the intrusion cannot change how the question itself is read.
  • Scale up: Gemma 3 12B is the planned next model, run on Colab.
  • Free answers, scored blind, to see whether the model names the injected concept beyond what priming explains.
  • Find a positive control: a case where the method is known to detect real sensitivity, so a null result means something.

Methods notes.

  • Hardware: a MacBook Pro (M1 Pro, 32 GB), with no training and no cloud compute.
  • Precision: Gemma ran in 32-bit floating point, because 16-bit overflowed and bfloat16 added up to 0.7 log-odds of rounding error.
  • Regression check: after every code change, a stored profile was re-run and had to give bit-identical numbers.
  • Validity rule: a condition was excluded when the model put less than half of its probability on "Yes" and "No" combined, that is, when injection had broken the answer format.
  • Intervals: 95% bootstrap intervals over concepts.
  • Trial counts: trials with an injection come in sets (a concept vector, its random vector, and in A3 and later the vector's parts), one per concept, question and prompt. Readings with nothing injected are one per question and prompt, not one per concept: the model's output is deterministic, so repeating an identical forward pass would give an identical number. Together they make 488,519 forward passes.
