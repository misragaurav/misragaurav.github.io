# Project 4, part 2: lexically matched items. See P4M_PRD.md and SPEC.md in this folder.

# Each item is a block:
#   === item id | topic | perspective
#   OPENER: shared first sentence(s)
#   S: frame | a | b      stake:   a first = self (it matters to someone),   b first = none
#   V: frame | a | b      valence: a first = good outcome,                   b first = bad outcome
#   T: frame | a | b      time:    a first = now (unfolding),                b first = past (remembered)
#   TAIL: shared closing sentence(s), word-for-word identical in all 8 versions
# A frame contains {0} and {1}. One level fills them (a, b); the other fills them (b, a).
# So every version of an item contains exactly the same words.
