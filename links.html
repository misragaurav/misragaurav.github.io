Useful links

A short, opinionated list: the places I actually read and the tools I actually used.

Interpretability and model psychology

  • Transformer Circuits Thread — Anthropic’s interpretability papers, including the concept-injection work on introspection that the introspection project builds on.
  • Anthropic research and the Alignment Science blog.
  • Neuronpedia — browse features and steering directions of open models in the browser.
  • Distill — the archive of clear, visual explanations of how neural networks work.
  • Alignment Forum and LessWrong — where much of the field thinks out loud. This site’s layout borrows from LessWrong.

Tools used in these projects

  • Hugging Face Transformers — loads open-weights models such as Gemma and Qwen.
  • PyTorch — the numerical engine; it runs on a Mac’s graphics processor.
  • TransformerLens and nnsight — libraries for recording and editing a model’s internal activity. My projects use plain PyTorch hooks, which do the same thing with less machinery.
  • Plotly — every figure on this site.
  • Claude Code — the coding agent I worked with to write and check the experiment code.

Learning the foundations

  • 3Blue1Brown on neural networks — the best visual introduction to how networks and transformers work.
  • Neural Networks: Zero to Hero — Andrej Karpathy builds a language model from scratch, in code.
  • ARENA — a hands-on curriculum in alignment research engineering, including interpretability.

Neuroscience and psychophysics tools I came from

  • EEGLAB — the EEG toolbox I used for pain studies.
  • MNE-Python — EEG and MEG analysis in Python.
  • AFNI and FSL — fMRI analysis.
  • Nilearn — pattern decoding and representational analysis for brain data in Python; the same methods appear in the emotion-readouts project.
  • PsychoPy — building psychophysics experiments.
